### Практическая работа №12 — адаптивная вёрстка

- добавлен `css/responsive.css` (подключается после `style.css` на всех страницах);
- подход Mobile First: базовые стили для телефона, расширения через `min-width` (640, 768, 900, 1024, 1280 px);
- на всех страницах есть `viewport`;
- адаптированы шапка и меню (бургер на телефоне), hero, сетка карточек (1 → 2 → 3 колонки), каталог с боковым фильтром, форма заявки (1 → 2 колонки), таблицы (прокрутка в `.table-scroll`), модальное окно;
- `picture` с тремя иллюстрациями для hero (`images/hero-mobile.svg`, `hero-tablet.svg`, `hero-desktop.svg`);
- у изображений карточек заданы `width`, `height`, `loading="lazy"`;
- проверенные ширины: 360, 430, 768, 1024, 1440 px — горизонтального скролла нет.

### Практическая работа №13 — доступность

- ссылка пропуска `skip-link`, один `h1` на странице, `aria-current` в меню;
- видимый `:focus-visible` на всех интерактивных элементах;
- подписи `label` у всех полей, ошибки связаны через `aria-describedby` / `aria-invalid`;
- бургер: `aria-expanded`, `aria-controls`, закрытие по Esc;
- поиск — `combobox` со стрелками, Enter и Esc; чат — `role="dialog"` и `role="log"`;
- движение отключается при `prefers-reduced-motion`.
- Lighthouse-отчёт: **нужно запустить самостоятельно** и положить скриншот в `lighthouse/` (index, catalog, product).
